# WideAgent

Claude와 ChatGPT 데스크톱(Windows)의 대화창을 넓게 쓴다.

두 앱 모두 넓은 본문 폭이 CSS에 이미 들어 있지만 설정으로 열려 있지 않아, 창을 아무리
키워도 가운데 840px만 쓴다. WideAgent는 트레이에 상주하면서 앱이 뜰 때마다 그 폭을
넓혀 준다. **앱 파일은 건드리지 않는다.**

## 설치

1. [Releases](../../releases) 에서 `WideAgent.exe` 를 받아 전용 폴더에 둔다.
   (로그·설정 파일이 exe 옆에 생긴다)
2. 실행하면 트레이에 아이콘이 생기고, 그때부터 Claude와 ChatGPT를 켤 때마다 알아서 넓어진다.
3. 트레이 메뉴에서 **Windows 시작 시 자동 실행**을 켜 두면 끝이다.

설치 프로그램도, 관리자 권한도, 별도 런타임도 필요 없다.

## 쓰면서 알아둘 것

**Claude에 적용하는 몇 초 동안 키보드와 마우스를 건드리지 않는다.** 화면 한가운데 진행
표시가 뜨는 동안이다(2초 안팎). 중간에 다른 창을 클릭하면 적용이 중단되고, 잠시 뒤
최대 3번까지 알아서 다시 시도한다.

**ChatGPT는 `ChatGPT (Wide)` 바로가기로 여는 것이 좋다.** 트레이 메뉴의
*ChatGPT 넓게 실행 바로가기 만들기* 로 바탕 화면에 만든 뒤, 작업 표시줄이나 시작 메뉴에
고정해 두고 기존 ChatGPT 아이콘 대신 쓰면 된다. 평범한 아이콘으로 연 ChatGPT는 구조상
앱을 껐다 켜야만 넓힐 수 있는데, 쓰던 중에 창이 사라졌다 돌아오면 놀라니 자동으로는 하지
않는다. 대신 풍선 알림이 뜨고, **그 알림을 클릭하면** 그 자리에서 재시작하며 넓혀 준다.

**다시 좁아 보이면 트레이 아이콘을 더블클릭한다.** 앱 업데이트나 로그아웃 뒤에는 넓힘이
풀릴 수 있다. 더블클릭과 트레이 메뉴는 항상 다시 적용한다.

## 이 프로그램이 건드리는 것

- **Claude**: DevTools를 열려면 앱 설정이 필요해서, 없으면 `developer_settings.json` 에
  `{ "allowDevTools": true }` 를 만든다. 기존 파일이 있으면 `.bak` 으로 백업한다.
  창에 코드를 붙여넣는 동안 잠시 클립보드를 쓰고, 쓰기 전 내용은 되돌려 놓는다.
- **ChatGPT**: 넓히려면 디버깅 연결이 필요해서, 앱을 `127.0.0.1` 의 임의 포트로 다시 띄운다.
  외부에서는 닿지 않지만, **그 PC 안의 다른 프로그램은 이 포트로 ChatGPT를 조작할 수 있다.**
  ChatGPT를 껐다 켜면 포트도 함께 사라진다.
- **기록**: exe 옆 `WideAgent.log` 에 적용 성공·실패만 남는다. 대화 내용은 읽지도 보내지도 않는다.
  네트워크는 위 로컬 포트 말고는 쓰지 않는다.

처음 실행할 때 Windows SmartScreen 경고가 뜬다. 코드 서명을 하지 않아서이고,
**추가 정보 → 실행**으로 넘기면 된다.

## 트레이 메뉴

| 항목 | 설명 |
|---|---|
| Claude에 지금 적용 | Claude에 즉시 적용 |
| ChatGPT에 지금 적용 | ChatGPT에 즉시 적용 (필요하면 재시작해서) |
| ChatGPT 넓게 실행 바로가기 만들기 | 바탕 화면에 `ChatGPT (Wide)` 생성 |
| Windows 시작 시 자동 실행 | 켜기/끄기 |
| 로그 열기 | `WideAgent.log` |
| 종료 | 상주 종료 |

## 폭 바꾸기

기본값은 1280px이다. 더 넓히려면 exe 옆에 **`WideAgent.width.txt`** 를 만들고 CSS 길이
값을 한 줄 적는다.

```
2560px
```

2560px이면 사실상 창 크기가 한계가 되어 본문이 창을 거의 꽉 채운다. `min(2400px,80vw)`
처럼 화면 비율로 줘도 된다. 파일을 지우면 1280px로 돌아간다.

**바꾼 뒤에는 트레이에서 종료하고 다시 실행해야 반영된다.**

## 해제

트레이 메뉴에서 자동 실행을 끄고 종료한 뒤 폴더를 지우면 된다.

## 빌드

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Windows에 기본으로 들어 있는 .NET Framework 4.x 컴파일러만 쓴다. 따로 설치할 것이 없다.
빌드 전에 실행 중인 WideAgent를 종료해야 한다. 아이콘까지 다시 만들려면 `-Icon` 을 붙인다.
